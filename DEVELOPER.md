**Project Description:**

RecipeBox is a full-stack MERN web application that enables users to discover, create, organize, and share recipes in a community-driven environment. The platform includes secure user authentication, recipe management, advanced search and filtering, cookbook collections, meal planning, image uploads, and social features such as comments, ratings, and following other users.

**Key Features:**

- User Registration & Login
- Secure JWT Authentication
- Create, Update & Delete Recipes
- Recipe Image Upload
- Advanced Search & Filters
- Follow & Unfollow Users
- Comments & Ratings
- Personalized Recipe Feed
- Digital Cookbooks
- Weekly Meal Planner
- Responsive User Interface
